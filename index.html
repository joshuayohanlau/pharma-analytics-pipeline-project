Skills Demonstrated

What this project proves I can do

Each card maps to a real-world analytics engineering competency. Every skill below is implemented in the codebase, not just described.

Incremental Model Design
fct_prescriptions.sql
Built a fact table using delete+insert incremental strategy with is_incremental() filtering. On subsequent runs, only new prescription records are processed — the same pattern used to handle millions of rows in production warehouses.
SCD Type 2 Snapshots
snap_drug_status.sql · snap_inventory_levels.sql
Implemented both snapshot strategies: timestamp-based tracking for inventory levels and check-based tracking for drug approval status and pricing. dbt manages valid_from / valid_to columns automatically.
Data Quality Testing
77 tests across all layers
Generic tests (unique, not_null, accepted_values, relationships), singular tests (custom SQL), custom generic tests (reusable macro), and dbt_utils tests (accepted_range). Full coverage from sources to marts.
Layered Architecture
staging → intermediate → marts
Three-layer DAG: 9 staging views (source-conformed), 3 ephemeral intermediate models (business logic joins), and 10 mart tables (dimensions + facts). Each layer has a clear purpose and materialisation strategy.
Jinja & Custom Macros
macros/
Wrote reusable Jinja macros: cents_to_dollars() for currency conversion, generate_surrogate_key() for hash keys, a custom generic test for positive values, and a logging macro for run-event hooks.
Model Contracts & Governance
_core__models.yml
Enforced column-level contracts on dim_drugs — the build fails if actual data types don't match the contract. Combined with source freshness checks (warn at 24h, error at 48h), hooks, and full doc() block documentation.
